# NEON BREACH

Juego cyberpunk de lógica y descifrado en español. Proyecto independiente, desarrollado con React, TypeScript, Tailwind CSS y TanStack Start.

## Desarrollo local

Requisitos: Node.js y npm o Bun.

```bash
npm install
npm run dev
```

## Comprobaciones

```bash
npm test
npm run lint
npm run build
```

Todo el hacking mostrado es ficción y forma parte de los puzles del juego. La aplicación no se conecta a redes reales ni realiza escaneos.
